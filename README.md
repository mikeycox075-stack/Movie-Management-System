Movie Management System

Here is a Movie management System I created in order to test my Java OOP skills.
This program allows users to record their favorite movies, search by genre, and delete movies.

How to use it: 
1. Download IntelliJ IDEA
2. Create a new project
3. Copy the files into the Src folder.
4. Then move the .txt files into the projects main file (Not the src); 
5. Then run the zoo App File.

Features:
1. Add Movie
2. Remove Movie
3. Find a Movie through Star rating, Actor or actress name, Movie Genre, Between dates of release, Movie Name.
4. List all the movies
5. Saves movies after user Exits
6. Create a movie report
